# Aplicación web

Este directorio alojará la aplicación Next.js de e-tajweed. Su responsabilidad será presentar, explicar y permitir explorar resultados; no definir reglas religiosas ni modificar el corpus.

`src/app` se reserva para App Router. La lógica de dominio deberá permanecer en `packages/engine` y el conocimiento aprobado en `knowledge`.
